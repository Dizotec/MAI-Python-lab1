# Toolkit CLI

Консольная утилита на Python, совмещающая калькулятор выражений и конвертер физических величин. Вычислительное ядро полностью изолировано от интерфейса командной строки (CLI) и общается с ним через возвращаемые значения (`return`).

## Реализованный функционал

### Калькулятор
* **Парсинг и перевод в ОПЗ:** Реализован посимвольный разбор инфиксной строки, выделение чисел и операторов, корректное определение унарных знаков (`+` и `-` перед числами) и перевод выражения в Обратную польскую запись по алгоритму «Сортировочная станция» Дейкстры.
* **Вычисления на стеке:** Расчеты постфиксного выражения выполняются на стеке на базе `collections.deque`. Поддерживаются бинарные операции `+`, `-`, `*`, `/`, `%` и унарный минус (`~`).
* **Обработка приоритетов и скобок:** Соблюдается математический приоритет операторов. Поддерживается вложенность круглых скобок любой глубины. Любые пробельные символы между токенами игнорируются автоматически.
* **Точность и округление:** Для исключения погрешностей плавающей точки все расчеты внутри ядра проводятся через тип `Decimal`. Результат форматируется строго до двух знаков после запятой методом `ROUND_HALF_UP`.
* **Вычисление остатка (%):** Оператор `%` корректно обрабатывает отрицательные операнды и унарные минусы (реализована логика остатка со знаком делителя).
* **Запрет встроенных интерпретаторов:** Разбор строки написан вручную. В коде исключены вызовы `eval()`, `exec()`, `ast.literal_eval()` или сторонних библиотек парсинга.

### Конвертер
* **Чтение конфигурации:** Таблица коэффициентов перевода вынесена из кода во внешний конфигурационный файл `units.json`. Данные загружаются динамически, абсолютный путь к файлу вычисляется через `os.path`.
* **Конвертация длины и массы:** Поддерживается перевод между единицами длины (`mm`, `cm`, `m`, `km`) и единицами массы (`g`, `kg`). Кросс-конвертация между несовместимыми группами блокируется.
* **Конвертация температур:** Реализован взаимный перевод между шкалами Цельсия (`c`), Кельвина (`k`) и Фаренгейта (`f`). Присутствует жесткая валидация нижнего предела температуры (абсолютный ноль).
* **Форматирование строк и типов:** Символы физических величин приводятся к нижнему регистру, что обеспечивает регистронезависимость ввода. Результат любой успешной конвертации возвращается как тип `float`.

### Архитектура пакета и CLI
* **Разделение слоев:** Процессы разбиты по независимым файлам: `tokenization.py`, `validation.py`, `calculator.py`, `converter.py`. Внутри ядра нет ни одного вызова `input()` или `print()`.
* **Логирование истории:** Каждое успешно посчитанное калькулятором выражение вместе с итоговой строкой ответа автоматически сериализуется и дописывается в конец локального файла `results.json`.
* **Вывод ошибок:** Обработка исключений централизована в `errors.py`. Все типы ошибок (пустое выражение, запрещенные знаки, пропущенный операнд, два бинарных оператора подряд, деление/остаток на ноль, неизвестная или несовместимая единица, неверное числовое значение) выводятся в поток `sys.stderr`, а программа завершается с кодом `2`. При успешном выполнении код завершения равен `0`.

### Тестирование и проверки
* **Автотесты:** Написано 27  изолированных тестов на базе `pytest`. Покрыты все позитивные и негативные ветки вычислений, лимиты конвертера и перехват стандартных потоков CLI через `capsys`. Тесты импортируют ядро напрямую без использования `subprocess`.
* **Линтинг:** Исходный код проверен и отформатирован статическим анализатором `Ruff`.

## Структура проекта
* `src/toolkit/` — папка с исходным кодом пакета.
* `src/toolkit/__main__.py` — точка входа для CLI.
* `src/units.json` — конфигурационный файл коэффициентов.
* `tests/test_core.py` — автоматические тесты.

## Использование

### Калькулятор
python -m toolkit calc "2 + 3 * 4"
# Вывод: 2 + 3 * 4=14.00

python -m toolkit calc "-(3 + 5)"
# Вывод: -(3 + 5)=-8.00

python -m toolkit calc "5 % -2"
# Вывод: 5 % -2=-1.00

### Конвертер величин
python -m toolkit convert 1000 --from mm --to m
# Вывод: 1.0

python -m toolkit convert 1.5 --from kg --to g
# Вывод: 1500.0

python -m toolkit convert 0 --from c --to f
# Вывод: 32.0

### Справка
python -m toolkit --help

## Тестирование и линтинг

Запуск тестов:
python -m pytest

Проверка линтером:
ruff check .
